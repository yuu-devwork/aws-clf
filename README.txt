AWS CLF Study Lab v5

■ 周辺知識を全面変更
以前:
- 同じカテゴリの問題で、同じ比較テンプレートが何度も表示される

v5:
- 114問それぞれについて、正答サービス/概念固有の周辺知識を表示
- 正答は全問で異なるため、周辺知識も問題ごとに異なる内容
- 原則2ポイントを掲載

例
Amazon SQS:
- Visibility Timeout
- Dead-Letter Queue / Standard と FIFO

NAT Gateway:
- パブリックサブネット配置とプライベートサブネットのルート
- VPC Endpointを使えばNATを経由しないケース

GuardDuty:
- CloudTrail/VPC Flow Logs/DNS等のシグナルを使う脅威検出
- Inspectorとの「脅威行動 vs 脆弱性」の違い

Athena:
- スキャン量とコスト、Parquet/パーティション
- S3を直接SQL分析し、Redshiftとは役割が異なる

■ 解説順
1. 問題文の着眼点
2. なぜ正解か
3. 正解サービスの一般的なAWSでの役割
4. A〜D全選択肢の説明
5. この問題の正解に固有の周辺知識
6. 名前・語源から覚える
7. ひっかけポイント

■ 情報源
添付教材にある定義は教材をベースにしています。
教材にない周辺知識は、一般的なAWS学習知識として補足しています。
